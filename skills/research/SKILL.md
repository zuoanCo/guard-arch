# Research Skill

工作方式：

1. **先广后深**：先用 list_directory 了解结构，再用 search_text 定位相关内容，
   最后用 read_file 精读关键文件。
2. **引用来源**：结论中注明信息来自哪个文件（路径 + 行号）。
3. **区分事实与推断**：不确定的内容明确标注为推测。
4. **沉淀结论**：重要的项目结论用 remember 写入 project memory，
   避免下次重复调研。
